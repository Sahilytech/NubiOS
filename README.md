# NubiOS

> A modular, privacy-first AI desktop assistant for Windows.

NubiOS is being built as a serious desktop product: local-first memory, controlled automation, deterministic commands, optional AI providers, and an extensible plugin architecture.

## Status

### Implemented
- PySide6 desktop UI with dashboard, chat, tasks, memory and settings views
- Deterministic command engine for core actions
- SQLite persistence for conversations, tasks and memories
- Central permission manager
- Safe filesystem search limited to configured directories
- Configurable application registry and Windows launching
- Structured local logging
- Offline mock AI provider
- Automated tests
- Windows PyInstaller build script
- GitHub Actions CI

### Experimental
- Provider abstraction for future local/cloud AI
- Plugin manifest model

### Planned
- Whisper voice input
- Text-to-speech
- Vision/screenshot analysis
- Semantic memory search
- Web provider
- Full plugin execution sandbox

## Quick start

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
$env:NUBIOS_MOCK_AI="true"
python -m nubios.main
```

For development dependencies:

```powershell
pip install -e ".[dev]"
pytest
```

## Configuration

Copy `.env.example` to `.env` and configure allowed directories. NubiOS does not expose the entire filesystem by default.

Example:

```text
NUBIOS_ALLOWED_DIRECTORIES=C:\Users\YourName\Documents;C:\Users\YourName\Downloads
```

## Security model

NubiOS does not execute arbitrary shell commands generated by an AI model. Actions are explicit, permission-gated operations. Filesystem access is restricted to configured directories, and sensitive operations can require confirmation.

Secrets must never be committed to the repository.

## Testing

```powershell
pytest
```

Tests are designed to run without cloud AI, Ollama, Whisper, or external services.

## Building Windows executable

Run `build_exe.bat` on Windows after installing the project dependencies. The script runs tests before invoking PyInstaller.
